# Contribuir

1. Cree una rama con un objetivo único.
2. Mantenga los controladores delgados: la validación va en Form Requests y las reglas de permisos en Policies.
3. Añada o actualice pruebas Feature al modificar comportamiento HTTP o autorización.
4. No incluya `.env`, tokens, logs, `vendor`, `node_modules` ni artefactos de compilación.
5. Use commits pequeños y descriptivos con formato Conventional Commits.
